# UTi260B Thermal Studio

[English](README.md) | **ภาษาไทย**

![icon](uti260b/gui/thermometer.png)

โปรแกรมบน Windows สำหรับกล้องถ่ายภาพความร้อน **UNI-T UTi260B** ทำได้ดังนี้
- แสดงภาพสดบนคอมพิวเตอร์ และวัดอุณหภูมิรายพิกเซล
- บันทึกค่าตามเวลา ถ่ายภาพ และอัดวิดีโอ
- แจ้งเตือนเมื่ออุณหภูมิเกินค่าที่ตั้งไว้
- ใช้ได้ทั้งภาษาไทยและภาษาอังกฤษ

## ดาวน์โหลด (Windows)

ดาวน์โหลด **`UTi260B-Thermal-Studio.exe`** จากหน้า [Releases](https://github.com/PolarZ5/uti260b-thermal-studio/releases/latest) แล้วดับเบิลคลิกได้เลย ไม่ต้องติดตั้ง Python
- ไฟล์ขนาดประมาณ 95 MB ครั้งแรกอาจใช้เวลาเปิดราว 10–30 วินาที
- ไฟล์ยังไม่ได้เซ็นดิจิทัล ถ้า Windows SmartScreen เตือน ให้กด **More info → Run anyway**
- ค่าตั้งเก็บที่ `%APPDATA%\UTi260B Thermal Studio\` ไฟล์ที่บันทึกจะอยู่ที่ `Documents\UTi260B Captures\` (เปลี่ยนโฟลเดอร์ได้ในโปรแกรม)

## ตั้งค่าที่ตัวกล้อง

1. `SET` → Settings → **USB Mode → USB Camera**
2. Image Mode → **Thermal** (ถ้าเป็น Fusion/PIP ส่วนที่เป็นภาพกล้องธรรมดาจะวัดอุณหภูมิไม่ได้)
3. เปิด **Center Spot** ไว้ ถ้าเปิด **Point Temperature** ด้วย โปรแกรมจะอ่านค่าจุดเหล่านั้นมาช่วยสอบเทียบ
4. เสียบสาย USB-C เข้าคอม โปรแกรมจะหากล้องและเชื่อมต่อให้อัตโนมัติ

> ใช้พอร์ต USB-A 5V ธรรมดา มีรายงานว่าที่ชาร์จเร็ว USB-C PD อาจทำให้วงจรไฟของกล้องเสียหาย

ถ้ายังไม่มีกล้อง ให้เปิด **⋯ → โหมดสาธิต** โปรแกรมจะเล่นภาพตัวอย่างใน `samples/`

  - ปุ่มยางลบ (ล้างจุด/ROI/พื้นที่ไม่วัด)
  - หยุดภาพ
- **แผงขวา:**
  - การ์ด Max / Min / จุดกลาง / เฉลี่ย
  - ตารางจุดวัด (คลิกที่พิกัดเพื่อแก้ตำแหน่ง)

  - palette และแจ้งเตือนอุณหภูมิสูง

  - สเกลอุณหภูมิ หน่วย และตัวเลือกการสอบเทียบ
  - clean ภาพ และล็อกช่วงสี
  - แจ้งเตือนอุณหภูมิต่ำ
  - ขนาดวิดีโอ
  - backend และการหมุนภาพ

**กราฟและการบันทึกค่า**
- **เริ่มบันทึก:** กด **● เริ่มบันทึกข้อมูล** เพื่อเก็บค่า Max, Min, จุดกลาง, เฉลี่ย, ROI, จุดวัด P1–P6 และจุดของกล้อง P1–P3 ตามความถี่ที่เลือก (ทุกเฟรม ถึง 1 นาที) มีปุ่มพัก/ต่อ
- **เปิด/ปิดเส้น:** คลิกปุ่มชื่อเส้นเหนือกราฟ โปรแกรมจะจำไว้ใช้ครั้งต่อไป
- **ดูค่า:** ชี้เมาส์บนกราฟเพื่อดูค่าทุกเส้น ณ เวลานั้น เลือกช่วงเวลาที่แสดงได้ (ทั้งหมด / 1 / 5 / 15 / 60 นาทีล่าสุด) และมีตารางสรุปค่าล่าสุด/ต่ำสุด/สูงสุด/เฉลี่ย
- **Export CSV:** กดได้ทุกเมื่อ ถ้าเปิด "เขียน CSV ระหว่างบันทึก" (ขั้นสูง › บันทึก) โปรแกรมจะเขียนลงไฟล์ทีละแถวระหว่างวัด ข้อมูลจึงไม่หายแม้โปรแกรมปิดกะทันหัน

- ช่องที่ว่างแปลว่าวัดค่านั้นไม่ได้ในแถวนั้น
- ตอน Export จะตัดคอลัมน์ที่ไม่มีข้อมูลออก

## หลักการวัดและข้อจำกัด (ควรอ่าน)

ในโหมด USB Camera กล้องจะส่ง**ภาพหน้าจอเป็นวิดีโอสี** (UVC) ไม่ได้ส่งค่าอุณหภูมิดิบ โปรแกรมจึงคำนวณย้อนกลับจากภาพตามขั้นตอนนี้

1. หาแถบสีด้านขวาของจอ เพื่อรู้ว่ากล้องใช้ palette อะไร
2. แปลงสีของแต่ละพิกเซลกลับเป็นตำแหน่งบน palette (0–254)
3. อ่านตัวเลขที่กล้องแสดงบนจอด้วย OCR ได้แก่
   - ค่า Max/Min ที่หัวและท้ายแถบสี
   - ค่าจุดกลาง "+ xx.x°C" ที่มุมซ้ายบน
   - ตัวเลขของจุด Point Temperature ของกล้อง
4. แปลงตำแหน่งบน palette เป็นอุณหภูมิด้วย**การสอบเทียบหลายจุดแบบทางเดียว (monotone)** ที่ผ่านทุกค่าข้างต้น เรียงจาก Min → จุดต่าง ๆ → Max
5. หาเป้าจุดร้อน/เย็นของกล้อง (กรอบสีแดง/เขียว) ค่า Max/Min จึงได้ทั้งค่าและตำแหน่งตรงกับที่กล้องแสดง

ผลทดสอบกับกล้องจริงคือ Max, Min และจุดกลางตรงกับที่กล้องแสดง ถ้าไม่สอบเทียบด้วยจุดกลาง ค่าช่วงกลางจะคลาดประมาณ 5 °C เพราะกล้องเร่งคอนทราสต์ก่อนลงสี

รายละเอียดสัญญาณจากกล้อง
- ขึ้นในเครื่องเป็น "UVC Camera" (USB VID 1D6B / PID 0102)
- ภาพขนาด 240×321 ที่ประมาณ 10 fps มีแถวว่างเกินมา 1 แถว ซึ่งโปรแกรมตัดออกให้
- ใช้ได้เฉพาะ backend DirectShow

**ข้อจำกัด**
- **ค่า Max / Min / จุดกลาง / จุดของกล้อง ตรงกับกล้อง** เพราะอ่านมาจากค่าที่กล้องวัดเอง ส่วนพิกเซลอื่นเป็นการประมาณ ถ้าภาพมีช่วงอุณหภูมิกว้างอาจคลาดได้ 1–3 °C ([ที่มา](https://github.com/Santi-hr/UNI-T-Thermal-Utilities/blob/main/docs/temperature_issue.md)) ถ้าช่วงแคบจะแม่นขึ้น
- **พิกเซลที่ถูกตัวหนังสือหรือเป้าเล็งของกล้องบังจะไม่ถูกนำมาวัด** โปรแกรมตรวจจับส่วนที่บังได้เอง และลากกรอบ "ไม่วัด" เพิ่มเองได้
- **ถ้าเปิดเมนูของกล้องค้างไว้** แถบเมนูจะบังค่า Min โปรแกรมจะเตือนให้กด Back
- **สั่งงานกล้องจาก PC ไม่ได้:**
  - UTi260B ไม่มีช่องทางรับคำสั่งผ่าน USB และโปรแกรม UTi Thermal Analyzer ของ UNI-T เองก็ทำได้แค่ฉายภาพ
  - การตั้ง palette, emissivity, gain, alarm ของกล้อง และการบันทึกลง SD ต้องทำที่ตัวกล้อง
  - โปรแกรมนี้จึงมีตัวควบคุมฝั่ง PC ของตัวเองแทน ได้แก่ palette, ช่วงสี, จุดวัด, ROI, การแจ้งเตือน, การบันทึก และหน้าตั้งค่าไดรเวอร์ UVC ของ Windows

## รันจากซอร์สโค้ด

```bash
pip install -r requirements.txt
```

```bash
python -m uti260b
```

หรือดับเบิลคลิก `run.bat` ถ้าต้องการ shortcut บนเดสก์ท็อปพร้อมไอคอน ให้รัน `powershell -File tools\make_shortcut.ps1`

ถ้าต่อกล้องครั้งแรก ให้รัน `python probe.py` เครื่องมือนี้จะบันทึกข้อมูลเหล่านี้ไว้ใน `probe_report/`
- ชื่ออุปกรณ์ และ VID/PID
- รูปแบบสัญญาณที่กล้องรองรับ
- ภาพตัวอย่าง
- ผลการถอดรหัส

## สร้าง .exe เอง

ใช้ venv ที่ติดตั้งแค่แพ็กเกจที่จำเป็น ไฟล์ .exe จะได้เล็ก

```bash
python -m venv .venv
```

```bash
.venv\Scripts\pip install -r requirements.txt pyinstaller
```

```bash
.venv\Scripts\pyinstaller UTi260B-Thermal-Studio.spec
```

ผลลัพธ์อยู่ที่ `dist/UTi260B-Thermal-Studio.exe`

## ปัญหาที่พบบ่อย
- **กล้องต่อแล้วหลุดทุก 4–5 วินาที:** ให้เปลี่ยนพอร์ต USB หรือเปลี่ยนสาย (ตอนทดสอบ แก้ได้ด้วยการย้ายพอร์ต)
- **ไม่มีอะไรขึ้นเลยตอนเสียบ:** อาจเป็นสายชาร์จอย่างเดียว หรือกล้องยังไม่ได้ตั้ง USB Mode = USB Camera
- **เฝ้าดูการเชื่อมต่อ:** `python tools/watch_camera.py` จะแสดงเวลาที่กล้องต่อ/หลุด และลองดึงภาพให้
